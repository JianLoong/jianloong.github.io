Maze generation is a fascinating application of graph theory and algorithms. This interactive demo lets you generate mazes using different algorithms and types, inspired by the open-source [Maze Generator by razimantv](https://github.com/razimantv/mazegenerator).

## How to use
- Choose the maze type (Rectangular or Circular).
- Choose the algorithm (DFS or Prim's; circular mazes use DFS).
- Set the width and height of the maze.
- Click **Generate** to create a new maze.
- Explore the SVG maze below!
