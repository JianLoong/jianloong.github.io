## Project Overview

This is an example of how to create a project post that will automatically appear on your projects page. To create a project post:

1. **Add the "project" tag** to your post's frontmatter
2. **Write your project content** as a regular blog post
3. **The post will automatically appear** on the `/projects` page

## How It Works

The projects page uses a utility function `getProjectPosts` that filters all blog posts to only show those with the "project" tag. This means you can:

- Create project posts in any year folder
- Use all the same features as regular blog posts (images, code blocks, etc.)
- Have them automatically organized and displayed on the projects page

## Project Features

- Real-time messaging using WebSockets
- User authentication and authorization
- Message persistence with MongoDB
- Responsive React frontend
- Docker containerization

## Technologies Used

- **Backend**: Node.js, Express, Socket.io
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: MongoDB
- **Deployment**: Docker, AWS

## Getting Started

To create your own project post:

1. Create a new markdown file in any year folder under `src/data/blog/`
2. Add the "project" tag to the frontmatter
3. Write your project content
4. The post will automatically appear on the projects page

This system gives you the flexibility to create detailed project posts while keeping them organized and easily discoverable.
